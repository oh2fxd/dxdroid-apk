# DxDroid APK (Public Releases)

Precompiled Android APK distribution repository for **DxDroid** — Real-Time Amateur Radio DX Spot Mapper for Android phones and tablets.

> Source code is maintained in the private repository `oh2fxd/dxdroid`.

## Download
- **[dxdroid.apk](https://raw.githubusercontent.com/oh2fxd/dxdroid-apk/main/dxdroid.apk)** — Latest build (`v1.4.43`)
- **[version.json](https://raw.githubusercontent.com/oh2fxd/dxdroid-apk/main/version.json)** — OTA update metadata

## Key Features
- **Live PSKReporter MQTT Stream**: Real-time amateur radio spots across all HF/VHF bands (160m – 70cm) and modes (FT8, FT4, CW, SSB, JS8, WSPR).
- **2-Way QSO Detection**: Automatically highlights confirmed bidirectional QSOs and tracks friend callsigns across all bands.
- **FT8CN / GridTracker Maidenhead Shading**: Optional semi-transparent band-colored 4-character grid square overlays and adaptive zoom-based label decluttering.
- **Built-in OTA Updater**: Checks `version.json` and installs new APK releases directly inside the app.

## Installation
1. Download [`dxdroid.apk`](https://raw.githubusercontent.com/oh2fxd/dxdroid-apk/main/dxdroid.apk) to your Android device.
2. Open the file and allow installation from unknown sources when prompted.
3. Enter your callsign and Maidenhead grid locator in the Settings sheet.
